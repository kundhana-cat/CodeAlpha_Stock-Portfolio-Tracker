Abstract




This program implements a Simple Stock Portfolio Tracker using Python. It allows users to calculate the total value of their stock investments based on predefined stock prices. The program displays a list of
available stocks with their prices per share and repeatedly prompts the user to enter a stock symbol and quantity until the user chooses to finish. It validates user input, handles invalid stock symbols and incorrect
quantity entries, and computes the value of each selected stock. Finally, it calculates and displays the total portfolio value, helping users understand the overall worth of their selected stock holdings in a simple
and interactive manner








FEATURES OF THE PROGRAM:








- Predefined Stock List
Contains a fixed set of popular stock symbols with their prices per share.

- User-Friendly Interface
Displays available stocks and guides the user with clear prompts.

- Continuous Input Until Exit
Allows users to add multiple stocks until they type done.

- Input Validation

Checks for valid stock symbols

Ensures quantity entered is an integer

- Error Handling
Displays appropriate messages for invalid stock names or incorrect quantity inputs.

- Automatic Value Calculation
Calculates the value of each stock based on quantity and price.

- Total Portfolio Calculation
Keeps a running total and displays the final portfolio value.

- Modular Design
Uses a function and __main__ block for structured and reusable code.

- Simple and Efficient Logic
Uses Python dictionaries and loops for quick data processing.
